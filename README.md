# Landing Page - Riskcombat 🥊

Este proyecto es una landing page para promocionar un evento de peleas, desarrollada con **Bootstrap, JavaScript y Sass**. La web incluye información sobre los peleadores, categorías de peso y una barra de búsqueda para filtrar fácilmente a los competidores.

## 🚀 Tecnologías utilizadas

- **HTML5**: Estructura semántica del sitio.  
- **CSS3 / Sass**: Estilos personalizados y optimizados.  
- **Bootstrap**: Para una interfaz responsiva y moderna.  
- **JavaScript**: Dinamismo en la interacción del usuario.  

## 📌 Funcionalidades

- 📜 **Diseño responsivo** compatible con dispositivos móviles y escritorio.  
- 🔍 **Barra de búsqueda en tiempo real** para filtrar peleadores por nombre o categoría.  
- 🎨 **Estilos optimizados con Sass** para mejor mantenimiento del código.  
- ⚡ **Carga rápida** gracias a la optimización de recursos.
